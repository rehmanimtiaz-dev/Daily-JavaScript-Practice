🚀 Daily JavaScript Practice

Welcome to my Daily JavaScript Practice repository! This repo is a complete, phase-by-phase collection of my daily coding exercises, core JavaScript concepts, ES6+ features, problem-solving snippets, and vanilla JS projects as I build a strong foundation for React and the MERN stack.

📌 Topics & Learning Roadmap (11 Phases)

Phase 1 — Modern ES6+ Syntax

[ ] let vs const vs var (scope, hoisting, temporal dead zone)

[ ] Arrow functions vs normal functions (this ka farak)

[ ] Destructuring — array aur object dono

[ ] Spread operator (...) — arrays, objects, function calls mein

[ ] Rest parameters (...args)

[ ] Template literals (`Hello ${name}`)

[ ] Short-circuit evaluation (&&, ||, ?? — nullish coalescing)

[ ] Ternary operator (condition ? a : b)

[ ] Optional chaining (?.)

Phase 2 — JavaScript Fundamentals (Core Language)

[ ] Data types: string, number, boolean, null, undefined, symbol, bigint

[ ] Type coercion aur == vs ===

[ ] Variables scope: global, function, block scope

[ ] Operators: arithmetic, comparison, logical, assignment

[ ] Conditional statements: if/else, switch

[ ] Loops: for, while, do...while, for...of, for...in

[ ] Functions: declaration vs expression, default parameters, IIFE

[ ] this keyword — different contexts mein kaise behave karta hai

Phase 3 — Arrays & Objects (Deep Dive)

[ ] Array methods: map, filter, reduce, forEach, find, findIndex, some, every, sort, slice, splice, includes, flat, flatMap

[ ] Object methods: Object.keys, Object.values, Object.entries, Object.assign, Object.freeze

[ ] Nested objects/arrays ko access aur update karna (immutability ka concept)

[ ] Array vs Object — kab kya use karna hai

[ ] Shallow copy vs Deep copy

Phase 4 — Functions & Scope (Advanced)

[ ] Closures — kya hain aur kyun important hain

[ ] Higher-order functions (functions jo functions return/accept karte hain)

[ ] Callback functions

[ ] Pure functions vs impure functions

[ ] Function currying (basic level)

[ ] call, apply, bind

Phase 5 — Asynchronous JavaScript (Critical for React/MERN)

[ ] Synchronous vs Asynchronous code

[ ] Callback functions aur "Callback Hell"

[ ] Promises — then, catch, finally

[ ] async/await syntax

[ ] Promise.all, Promise.race, Promise.allSettled

[ ] Event loop, call stack, microtask/macrotask queue (concept level samajhna)

[ ] setTimeout, setInterval

Phase 6 — Fetch API & Working with Data (Backend Connection Prep)

[ ] fetch() API — GET/POST requests

[ ] JSON — JSON.stringify, JSON.parse

[ ] Error handling with try/catch

[ ] Working with APIs (dummy APIs jaise JSONPlaceholder par practice)

[ ] HTTP basics: methods (GET, POST, PUT, DELETE), status codes, headers

Phase 7 — DOM Manipulation (Must-Know Before React)

[ ] document.querySelector / getElementById

[ ] Event listeners (addEventListener)

[ ] Event bubbling/capturing (basic)

[ ] Creating/removing elements dynamically

[ ] Form handling in vanilla JS

Note: React khud DOM manipulate karta hai (Virtual DOM), lekin agar aapko pata ho ke "neeche kya ho raha hai", to React ki logic samajhna bohot asaan ho jata hai.

Phase 8 — OOP in JavaScript (Essential for MERN Backend)

[ ] Objects aur constructors

[ ] class syntax, constructor method

[ ] Inheritance (extends, super)

[ ] Prototypes aur prototype chain (concept level)

[ ] Encapsulation basics

Phase 9 — Modules & Tooling (Modern JS Workflow)

[ ] ES Modules: import / export

[ ] CommonJS vs ES Modules (require vs import) — Node.js ke liye zaroori

[ ] npm basics: package.json, installing packages

[ ] Basic understanding of Node.js runtime (React se pehle iska pata hona chahiye)

Phase 10 — Error Handling & Debugging

[ ] try/catch/finally

[ ] Custom errors (throw new Error())

[ ] Browser DevTools — console, breakpoints, network tab

[ ] Debugging mindset — console.log se aagay (debugger statement)

Phase 11 — Practice Projects (Vanilla JS)

Har concept seekhne ke baad chhoti chhoti cheezain banao — is se React ki value samajh aayegi ke wo kya problems solve karta hai:

[ ] To-Do List (array methods, DOM, localStorage)

[ ] Weather App (fetch API, async/await)

[ ] Quiz App (objects, arrays, event handling)

[ ] Expense Tracker (arrays, reduce, localStorage)

[ ] Simple Calculator (functions, DOM events)
